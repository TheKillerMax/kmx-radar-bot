KMX RADAR

Detectamos lo que importa.

KMX RADAR es un proyecto informativo automatizado orientado a actualidad global, contexto y verificación de fuentes.

Cómo funciona

Detectamos cobertura reciente → agrupamos artículos sobre el mismo acontecimiento → buscamos fuentes independientes y fuentes primarias → aplicamos umbrales editoriales → redactamos y generamos una tarjeta gráfica → publicamos solo cuando la evidencia supera los controles.

Estados

VERIFICADO: existe corroboración suficiente y una fuente primaria/oficial. CORROBORADO: convergen varias fuentes independientes. EN DESARROLLO: la información sigue incompleta. SIN CONFIRMAR: no se publica como hecho.

Correcciones

Si un dato material cambia, KMX RADAR debe actualizarlo de forma visible. Los errores relevantes no se corrigen silenciosamente.

Uso de automatización

La automatización ayuda a detectar, contrastar, resumir y diseñar. Ningún modelo de IA se considera por sí mismo una fuente.
