# KMX RADAR — instrucciones para ChatGPT

Antes de trabajar, lee **EDITORIAL_SYSTEM.md** completo. Ese documento define el estándar FORJA-Editorial para investigación, fact-checking, lenguaje, diseño, derechos visuales y control de calidad.

Este expediente es solo una entrada automática. No publiques ni redactes basándote únicamente en él.

Rutas de este expediente:
- manifest.json
- previous_posts.json
- events/*/event.json
- events/*/evidence.md
- brand/logo.png
- EDITORIAL_SYSTEM.md

Flujo obligatorio:
1. revisa todos los candidatos;
2. investiga nuevamente en la web;
3. prioriza fuentes primarias/oficiales y documentos originales;
4. comprueba fechas, lugares, cifras, contexto y dependencia entre fuentes;
5. distingue hechos confirmados, declaraciones, inferencias y desconocidos;
6. evita duplicar historias ya presentes en previous_posts.json;
7. selecciona como máximo un acontecimiento realmente relevante;
8. redacta en español cotidiano y comprensible para una persona sin contexto previo;
9. prepara un plan visual con material real de Internet y derechos de reutilización verificables;
10. usa siempre el logo oficial de KMX RADAR; no generes ni recrees el logo;
11. no generes fotografías ni escenas sintéticas como evidencia;
12. crea el paquete editorial con ready_to_publish=false;
13. deja la producción visual y la publicación para las fases posteriores.

Nunca uses “carrusel” en el copy público. Usa “post”, “publicación”, “desliza” o “guarda este post” según corresponda. Usa “Reel” solo si el archivo publicado es realmente un Reel.

Para política y elecciones: presenta hechos y posiciones documentadas sin apoyar, oponerte, clasificar, puntuar ni predecir ganadores.

Si la evidencia no alcanza el estándar editorial, registra el ciclo como omitido y no prepares una publicación.
